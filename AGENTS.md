# Project Instructions

This is a Next.js application using:

- TypeScript
- React
- Drizzle ORM
- PostgreSQL
- Tailwind CSS

## General

- Prefer existing project patterns over introducing new abstractions.
- Keep changes focused on the requested task.
- Don't modify unrelated files.
- Prefer simple, direct implementations.
- Don't explain basic code unless asked.

## Next.js

- Keep database access on the server.
- Don't perform database queries from client components.
- Follow the existing App Router conventions.

## Drizzle

- Use the existing Drizzle schema and query patterns.
- Don't introduce another ORM or database abstraction.

## API

- Follow the patterns used by existing API routes.
- Validate input where appropriate.
- Return appropriate HTTP status codes.
